# ScriptShifter

ScriptShifter is the Library of Congress transliteration tool. It converts text between non-Latin scripts and the Latin alphabet, following the [ALA-LC Romanization Tables](https://www.loc.gov/catdir/cpso/roman.html) used in library cataloging. Most scripts can be converted in both directions: from the original script to Roman letters (romanization), and from Roman letters back into the original script.

ScriptShifter is available as a web interface for interactive use and as a REST API for use by other applications, such as the [Marva](https://bibframe.org/docs/view/documentation-marva-manual/index.md) BIBFRAME editor. Transliteration rules are kept in plain-text tables that can be corrected and extended without programming.
